README — CabalREADME.md · 286 lines

Agentic development configuration in one place. Cabal is the local control panel for managing a machine's Claude Code and Codex setup: deploying global agent configuration, checking setup drift, restoring backups, managing MCP connections, initializing environment variables, scaffolding local project configuration, installing companion CLIs, and browsing the agent/skill knowledge map.

29 subagentsDomain experts auto-invoked when the task matches — @dotnet-architect, @react-architect, @secret-auditor…
26 skillsSlash-command workflows — /git, /pr, /orchestrate, /design, /skill-create…
hooks & rulesSessionStart project loading, PreToolUse guards, PostToolUse audit; conditional rules load per file type.
servicesa2a-bridge (Claude ↔ Gemini, 199 tests), orchestrator (autonomous PR review), mcp-bus (agent message bus).
deploy./run (terminal UI) · ./run-web-ui (this read-only browser UI) · plugin install via marketplace.
